🎲 Gesture Dice Roller

This project is a gesture-controlled dice game built using Python, OpenCV, and MediaPipe. The game uses a webcam to detect hand gestures. Players can guess a number by showing fingers and roll the dice by making a fist.

📌 Features

Real-time hand tracking

Finger counting using MediaPipe

Gesture-based dice rolling

Simple win / lose result system

Works using a webcam

🕹 How to Play

Show 1 to 6 fingers to select your guess.

Make a fist to roll the dice.

The program generates a random dice number.

If your guess matches the dice result → You Win.

Open your hand to restart the game.

🛠 Technologies Used

Python

OpenCV

MediaPipe
